Vie de la Station
Le bug qui parlait
Ananya — Bangalore
Ananya a trouvé un bug dans le système de gestion des nuages de Minorea. Pas un simple crash de routine, non, un message codé enfoui dans les logs, répété toutes les 87 secondes. Elle l'a décompilé en une nuit, cheveux en chignon défait, lunettes glissées sur le nez, trois écrans allumés. Le message n'était pas une erreur, c'était une adresse. Quelque chose dans les nuages demande qu'on vienne le chercher.
